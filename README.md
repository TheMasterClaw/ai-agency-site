# Nexus AI Agency Website

A high-converting AI agency website built with Next.js, Tailwind CSS, and Framer Motion.

## 🚀 Live Demo

The website is deployed and ready for production use.

## 📁 Pages

- **Home** (`/`) - Hero, Problem/Solution, Services, Results, Case Studies, Pricing, CTA
- **Services** (`/services`) - Detailed service offerings with pricing
- **Case Studies** (`/case-studies`) - Client success stories with ROI metrics
- **About** (`/about`) - Mission, values, process, tech stack
- **Contact** (`/contact`) - Calendly integration for booking calls

## 🎨 Design Features

- Premium dark mode aesthetic (like Linear/Vercel)
- Gradient text effects and glow animations
- Glass morphism cards
- Framer Motion scroll animations
- Mobile-responsive navigation
- Professional typography with Inter font

## 🛠 Tech Stack

- **Framework:** Next.js 14 (Static Export)
- **Styling:** Tailwind CSS 3
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Font:** Inter (Google Fonts)

## 📦 Build Output

The static site is exported to the `/dist` folder and ready for deployment to:
- Vercel
- Netlify
- GitHub Pages
- AWS S3
- Any static hosting

## 🚀 Deployment

```bash
# The dist folder contains the static build
cd dist

# Deploy to your hosting provider

```
